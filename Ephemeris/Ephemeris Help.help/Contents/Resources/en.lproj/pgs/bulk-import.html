Importing your log archive

If you have months or years of PHD2 logs sitting in a folder, one import builds the whole history — per rig, per night — in a single pass.

Run an import

  1. Open the Library (⇧⌘L) and click Import logs… in the toolbar — or choose File › Import Folder of Logs… (⇧⌘I).
  2. Pick the folder that holds your logs. The scan is recursive, so a top-level archive folder with per-year subfolders works fine.
  3. A progress window shows each file as it's processed; you can cancel between files.

Only files matching PHD2_GuideLog_*.txt are considered — debug logs (PHD2_DebugLog_*.txt) are skipped, as are PHD2's empty placeholder logs. Files over 500 MB are skipped too and reported in the import summary; the same limit applies when opening a log directly. The summary also lists any files that couldn't be read or parsed, so nothing disappears silently.

Safe to re-import

Every log is fingerprinted by a hash of its content. Re-importing the same folder later — say, your live ~/Documents/PHD2/ directory at the end of each month — never duplicates a night. Logs already in the library are matched by hash and their per-session detail and observations are refreshed against the current analysis instead, so re-importing after an Ephemeris update is the easy way to re-analyze your whole archive.

Rigs are created automatically

Each log's Equipment Profile = … header line names the PHD2 profile it came from. Logs are matched to existing rigs by that name; when no match exists, a rig is created automatically with its guide-train values pre-filled from the log header. The import summary lists any rigs it created — visit Rig profiles afterwards to add each one's imaging train so verdicts light up.

Folder access

Ephemeris is sandboxed, so choosing the folder in the import panel is also what grants read access to it. The grant is saved as a security-scoped bookmark, which is how double-click to open the original log in the Library keeps working in later launches without asking again. If you move your archive, run one import from the new location to re-establish access.

Caveat: Logs are read-only throughout — importing never modifies or moves your original files. Deleting a night from the library doesn't touch the log on disk either.
