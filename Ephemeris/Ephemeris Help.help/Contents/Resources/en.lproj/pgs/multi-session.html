Combining sessions

PHD2 starts a new section every time guiding stops — meridian flips, cloud breaks, dithering pauses. You can view several sections back-to-back as a single chart.

Select multiple sessions

  1. Click the first guiding session in the sidebar.
  2. ⇧-click the last one to select the contiguous range, or ⌘-click individual sessions to add them to the selection.
  3. The detail pane switches to a combined view labelled filename · N sessions combined.

How sessions are stitched

If every selected session has a wall-clock start date in the log header, the merger:

  • Sorts sessions chronologically by start date.
  • Rebases each session's frame timestamps relative to the earliest start.
  • Preserves real-world gaps (so a meridian flip shows up as a flat span rather than a fake jump).
  • Renumbers frames sequentially so the inspector's frame counts stay coherent.

If start dates are missing from the log header, the merger falls back to sequencing — sessions are concatenated in sidebar order with a 1-second nominal gap.

What still works on combined sessions

  • RMS, peak, drift, and polar-alignment statistics — computed on the merged dataset.
  • Hover, zoom, manual exclusions, frequency analysis.
  • Chart and CSV export — the export filename includes “combined”.

Single-session selection

Clicking a single session row collapses the combined view back to a single-session chart. Selecting Summary always returns to the overview.

Note: Calibration sections are not part of the combined chart. Selecting them while guiding sessions are also selected will route to the most recently selected one.
