Connecting Claude (MCP)

Ephemeris can expose your library to Claude over the Model Context Protocol, so you can ask "why did last Tuesday guide worse than usual?" and Claude answers from your actual data.

What Claude can see

Five read-only tools, surfaced from the library:

get_corpus_summaryHigh-level inventory of the library — a useful first call.
list_rigsRig profiles with their imaging-train values.
list_nightsPer-night rollups: RMS, integration, target, sub-quality rating.
list_observationsRecommender output, including severity and source authority.
get_aggregate_statsMedian / p75 / p90 RMS across a rig's nights.

Every observation carries its source_authority, so Claude can tell PHD2-canon advice apart from Ephemeris heuristics. An optional toggle, Allow Claude to add annotations, enables one write tool (add_annotation) so Claude can record equipment changes or notes on your behalf — it's off by default, and changing it only affects connectors you install afterwards (re-run Connect to update an existing one).

Opt-in, and it stays that way

The server is off by default and nothing is exposed until you turn it on. Open Ephemeris › MCP Server… and use Start server under Advanced. Your choice persists: once started, the server comes up automatically on later launches; once stopped, it stays off across launches until you start it again.

One-click setup

The MCP Server window has a connect tile for each client:

  • Connect to Claude Desktop — adds an entry to ~/Library/Application Support/Claude/claude_desktop_config.json.
  • Connect to Claude Code — adds an entry to ~/.claude.json.

Each tile points the client at a small stdio helper bundled inside Ephemeris.app — no terminal, no JSON editing. You'll see one macOS file-access prompt (click Grant Access); that authorizes Ephemeris to update the config file. Existing connectors in the file are preserved, and the config is written atomically. Restart the Claude client afterwards to see the Ephemeris tools appear.

Manual configuration

For other MCP clients, the Advanced disclosure shows the helper binary's path (use it as a stdio command entry) and a direct HTTP endpoint for clients that accept localhost URLs.

Privacy

Note: The server listens on the loopback interface (127.0.0.1) only — nothing leaves your Mac, there is no outbound network traffic, and no telemetry. All tools are read-only unless you explicitly enable the annotation-write toggle.
