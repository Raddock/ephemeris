Keyboard shortcuts

Everything below works only when a guiding session is open, except for File and Window commands.

File & window

⌘OOpen log
⌘WClose window
⌘?Ephemeris Help

Inspector and panels

⌥⌘IToggle inspector

Chart

⌘0Reset zoom (clear visible-range zoom)
⌘FOpen frequency analysis sheet
⌘EOpen Share / Export menu

Selection

⌘-click sidebarAdd/remove session from selection (combine view)
⇧-click sidebarSelect contiguous range of sessions
Click event in inspectorJump chart selection rule to that frame

Chart drag

Drag horizontallyZoom or exclude (depending on Drag mode)
Click empty areaDismiss pinned selection
