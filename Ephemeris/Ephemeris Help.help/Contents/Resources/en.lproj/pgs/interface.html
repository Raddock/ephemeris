The main window

A standard three-pane macOS layout: sessions on the left, chart in the middle, session metadata on the right.

Sidebar (left)

Lists the Summary plus every guiding and calibration section in the log. Multi-select with ⌘-click or ⇧-click to combine consecutive guiding sessions into one continuous chart — see Combining sessions.

Hide or show the sidebar with the toggle in the toolbar.

Detail pane (center)

Shows whichever section is selected:

  • Summary: aggregate stats and a sortable table of every section.
  • Guiding: the time-series chart, statistics strip, and chart controls bar.
  • Calibration: the dx/dy XY plot with concentric reference rings.

Inspector (right)

Always shows context for the selected section:

  • Session start time, frame counts, duration.
  • Statistics: RMS RA, RMS Dec, total RMS, peaks, drift, polar-alignment estimate.
  • Optics: pixel scale and declination.
  • Mount / AO: name, guide algorithms, guiding-enabled state.
  • Events: settling, dither, frame drops, lock changes — click any event to jump the chart to that frame.

Toggle the inspector with ⌥⌘I.

Toolbar

  • Share / Export — chart PNG, session CSV, frame CSV, log summary CSV.
  • Frequency analysis — opens an FFT sheet for the current session.
  • Reset zoom — clears any drag-to-zoom range.
  • Inspector toggle.

Chart controls bar (bottom)

When a guiding session is open, a control strip appears below the chart for fast access to:

  • Units — pixels or arc-seconds.
  • Axes — RA/Dec or dx/dy.
  • Drag mode — zoom or exclude.
  • Y scale — Auto, ±0.5″, ±1″, ±2″, ±5″, ±10″.
  • Overlays — series, diagnostics, annotations, scatter cluster.

All of these preferences persist between launches.
