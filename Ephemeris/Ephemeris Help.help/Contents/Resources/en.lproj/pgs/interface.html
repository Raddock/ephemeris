The main window

Ephemeris has two main surfaces: the Library window you launch into, and the document window you drill into when you open a log.

The Library window

The Library (⇧⌘L) is the app's home — a per-rig, multi-night view of everything you've opened or imported. Rigs and a time-range filter sit in the left sidebar; the detail pane stacks metric cards (median RMS, integration, sessions), a PHD2-hygiene strip, the trend chart, cross-night observations, and the Recent Nights table. Double-clicking a night there opens its original log in the document window described below. The full tour is in The Log Library.

The document window

The document window is the drill-in view for a single log, reached from the Library (or File › Open). It's a standard three-pane macOS layout: sessions on the left, chart in the middle, session metadata on the right.

Sidebar (left)

Lists the Summary plus every guiding and calibration section in the log. Each row shows the start time, type (guiding crosshair or calibration target), and duration.

  • Click any row to open that section in the detail pane.
  • ⌘-click or ⇧-click to combine consecutive guiding sessions — see Combining sessions.
  • Toggle the sidebar with the icon in the toolbar.

Detail pane (center)

Shows whichever section is selected:

  • Summary — aggregate stats and a sortable table of every session, with Best and Worst chips on the matching rows and a Total RMS quality bar visualising relative quality across the night.
  • Guiding — the time-series chart, statistics strip, and chart controls bar.
  • Calibration — the dx/dy XY plot with concentric reference rings.

Inspector (right)

Shows context for whatever is selected, organized as bordered cards. Each card has its own SF Symbol icon, title, and a thin border so sections don't run into each other:

  • Session — start time, frame counts, duration.
  • Statistics — RMS RA, RMS Dec, total RMS, peaks, drift, polar-alignment estimate. RA and Dec values are color-tinted to match the chart series.
  • Optics — pixel scale and declination.
  • Mount / AO — name, guide algorithms, guiding-enabled state, max durations, and minimum-move thresholds per axis.
  • Events — settling, dither, frame drops, lock changes. Click any event to jump the chart's selection rule to that frame.

Toggle the inspector with ⌥⌘I.

Toolbar

  • Log Library (⇧⌘L) — jump back to the multi-night Library to see this log in context.
  • Share / Export (⌘E) — chart PNG, session CSV, frame CSV, or log-summary CSV via the system share sheet.
  • Frequency analysis (⌘F) — opens the FFT sheet for the current session.
  • Reset zoom (⌘0) — clears any drag-to-zoom range.
  • Inspector toggle (⌥⌘I).

Chart controls bar (bottom)

When a guiding session is open, a control strip appears below the chart:

  • Units — pixels or arc-seconds.
  • Axes — RA / Dec or dx / dy.
  • Drag mode — zoom or exclude.
  • Y scale — Auto, ±0.5″, ±1″, ±2″, ±5″, ±10″.
  • Overlays — RA / Dec, corrections, star mass, SNR, events, limits, grid, scatter cluster, hover readout.

All preferences persist between launches.

Tip: Most controls in the chart bar are persistent per-app, not per-document — set them once and they stay across logs.
