Exporting

Share the chart as an image, or extract data as CSV for analysis in another tool.

Open the export menu

With a guiding session selected, click Share in the toolbar (⌘E). A menu opens with every available export.

Available exports

  • Chart (PNG) — renders the current chart at 2× resolution (typically 2560 × 1200 px). Reflects your current units, axes, Y scale, and overlay choices, but with no hover/selection rule for a clean image.
  • Session stats (CSV) — one row of summary numbers for the current session (RMS RA, RMS Dec, Total RMS, peaks, drift, polar align). Manual exclusions are reflected.
  • Frame data (CSV) — one row per frame: frame number, time, RA / Dec / dx / dy, durations, star mass, SNR, included flag. Use this to do your own analysis.
  • Log summary (CSV) — one row per guiding session in the log, with start time, frame count, and per-axis RMS. Useful for spreadsheet trend analysis across many nights.

How exports work

Every export is delivered through macOS's standard share sheet. From there you can:

  • Save the file to disk.
  • AirDrop it to another device.
  • Send via Mail or Messages.
  • Open in any registered destination (Numbers, Excel, etc.).

The app does not require a download or save-files entitlement — everything goes through the share sheet, so the app stays sandboxed and read-only.

CSV format

RFC 4180 — comma-separated, double-quote-escaped fields. UTF-8. The first row is a header. Numeric values use a period as the decimal separator regardless of system locale, so the files are spreadsheet-portable.
